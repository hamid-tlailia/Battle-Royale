# Character validation (build af65fa2)

Test bench: WebGL lobby with `?grid=mil|q|mixmil|mixq&from=N&n=2` (rows = outfits, columns = IDLE / RUN / JUMP / CROUCH / AIM / SHOOT)
and `?swap=1` (30 random outfit changes at runtime). Groups are strictly separated in code (`SoldierBody.Group`).

## Results
| Test | Result |
|---|---|
| Military, 11 outfits individually | PASS (no neck / waist / ankle gaps, shoulders and elbows hold) |
| Quaternius, 11 characters individually | PASS after rig fix (feet were stretched: IK rig) |
| Quaternius, mixed pieces | PASS - shared rig, no gaps; hats can overlap (see below) |
| Military, mixed pieces | FAIL - jagged waist seams, coat/legs clipping, distorted feet |
| Runtime outfit switching (30 swaps, both groups) | PASS 30/30 - animator running, gun at the hand, all pieces present, groups never mixed |
